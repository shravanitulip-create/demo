# Simple Interest Calculator

## Description
The Simple Interest Calculator is a simple tool that calculates the interest earned or paid on a principal amount over a specific period at a given rate of interest.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- **P** = Principal amount
- **R** = Annual rate of interest
- **T** = Time period in years

## Features
- Accepts principal amount as input.
- Accepts annual interest rate.
- Accepts time period in years.
- Calculates simple interest using the standard formula.
- Displays the calculated interest.

## Example

Given:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Calculation:

SI = (1000 × 5 × 2) / 100

**Simple Interest = 100**

## Technologies Used
- HTML
- CSS
- JavaScript

## Usage
1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate the simple interest.
5. View the result.
